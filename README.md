Ancient Introgression in Lepus Hares

This repository contains custom scripts and computational workflows used to investigate ancient introgression from the mountain hare (Lepus timidus) into the common ancestor of the broom hare (Lepus castroviejoi) and Italian hare (Lepus corsicanus), including analyses of genomic regions, introgression patterns, and their evolutionary history.

All code was used for the analyses presented in the following research paper:

Costa J, et al. (2026). [Manuscript title]. [Journal].

Further details on the context of the code and files are provided in the original manuscript.
